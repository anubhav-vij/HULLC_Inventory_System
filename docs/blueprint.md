# **App Name**: Inventory Management System

## Core Features:

- Dashboard View: Display a dashboard with the current product list, associated lot numbers, and quantities in each lot.
- Add Product: Form to add new product information including vendor, part number, location, and initial lot details (lot number, quantity, receipt date, expiration date).
- Edit Product: Form to edit an existing product. Allows adding or removing lots, and updating quantities. When quantities are adjusted, trigger a re-calculation of the product inventory levels, and present a success message or an alert.
- Delete Product: Ability to delete a product from the inventory system.
- Predictive Expiration Dates: Tool that predicts the expiration dates. An LLM uses inventory and external data to provide an informed range of likely expiry dates to set on inventory.

## Style Guidelines:

- Primary color: Soft blue (#77B5FE) to convey trust and stability.
- Background color: Light blue (#EBF4FA) for a clean and airy feel.
- Accent color: Subtle purple (#A385E0) for interactive elements and highlights.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a modern and neutral look.
- Simple and clear icons for navigation and actions.
- Clean and organized layout to ensure easy navigation.
- Subtle transitions on interactive elements, like button hovers and form submissions.
